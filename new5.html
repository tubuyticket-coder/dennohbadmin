SECURE CONNECTION

Integration settings

Connect the admin interface to your Supabase project and trusted admin endpoints.

Security: A single HTML file cannot safely hold a Supabase service-role key, PayHero Basic Auth, or EmailJS private credentials. Configure secrets in Supabase Edge Function settings and use an authenticated admin endpoint. The browser key must be a publishable/anon key protected by RLS and server-side admin authorization.

Supabase & admin API

Connection settings are saved on this device only; booking, ticket, payment, check-in, and announcement records are read from the official Supabase backend. Never enter a service-role key here.

Integration checklist

Official database dashboard. No sample bookings or local ticket register is used. Sign in with an authorized Supabase admin account to load the live records. Writes are rejected when the server connection is unavailable.
